# FireSonic Examples

Practical integration examples for the [FireSonic Integration Platform](https://firesonic.io) and its Developer SDK.

## Examples

- [Developer SDK Demo](developer-sdk-demo/) – An HL7 v2 ADT A01 to FHIR R4 integration using Java/Groovy scripts and semantic rules, demonstrated in IntelliJ IDEA.

Download the FireSonic Developer SDK from [firesonic.io](https://firesonic.io). Each example provides its own setup instructions.
